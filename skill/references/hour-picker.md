# 小时与分钟滚动选择契约

权威源：项目根 `hour_picker.py` 的 `CONTRACT`（仅小时）和 `TIME_CONTRACT`（小时＋分钟）、HTML/CSS/交互生成函数；导出位置 `design-tokens.json → components.hour_picker / time_picker`；人读规范为 `standards.html#hour-picker / #time-picker`。不要在新主题内复制另一套滚轮实现或固定颜色。

## 生成前明确语义

- “提醒小时、预约整点”：默认一天中的小时，整数 0–23，步进1，首尾循环；展示补零及单位，内部保存整数。09:00仅样张值，编辑回显实际值，新建默认由业务决定。
- “上午/下午”：支持用户12小时偏好时生成1–12与上午/下午列；上午12→0，下午12→12，其他下午值+12。HTML当前只演示24小时制；不得宣称12小时交互已实现。
- “持续几小时”：先从用户业务确定范围、步进、0的含义及最大值。缺失且影响业务时询问，不能把0–23当成时长范围。
- 需要分钟时使用现有 `time_card()` 双列组件，小时0–23、分钟0–59，默认步进1，样张09:30。可显式使用分钟步进5/10/15/30；已有分钟不匹配时生成器报错，应用需保留原值提示重新选择或允许细粒度编辑，不自动取整。日期、时区与夏令时不由两个整数解决。

## 双列分钟规则

两列等宽、间隔12pt，标签固定显示“小时/分钟”，保持选中行在同一水平线。分别滚动，支持首尾双向循环，分钟到00/59不改变小时或日期。任意一列未停稳均禁用确认；确认同时更新两值，取消/关闭同时恢复两值。保存整数hour/minute，展示补零HH:mm。步进改变候选值集合，不能将候选行号当分钟数：5分钟步进的第7行（索引6）为30分。

每列独立可访问名称和当前值，支持Tab切列、方向键及Home/End；大字号同步增加两列行高。保持原仅小时样张，新增双列样张也需覆盖浅深HC。当前不提供秒、12小时交互或持续时长变体。

## 统一外观与行为

项目基准为5个行位，中间选中，行高至少44pt，数字22pt、单位15pt起；按系统文字样式缩放。字号放大同步增加行高，空间不足时减少邻行或换原生替代样式；始终能到达确认和取消。原生滚轮几何尺寸由系统管理，这些不是Apple规定的固定值。

surface底、fill选中带、ink选中文字、sub邻行、accent_ui标记、control_border边线；确认使用accent/on_accent。所有文字保持可读，不透明度淡化。选中通过位置、字重和边界同时表达；四模式分别继承语义色。

滚动仅改草稿，停稳吸附整行后确认可用；确认才更新调用方。取消、返回、下拉关闭恢复原值，重新进入回显已保存值。边界首尾循环、不换日期；受限项需解释、不可确认；全无可用项展示原因和恢复操作。加载、保存失败与禁用是具体业务实现任务，不能假报成功。

原生优先 `Picker(...).pickerStyle(.wheel)` 或 `UIPickerView`，完整时间使用系统时间选择器。需验证名称/值/调整动作、VoiceOver、键盘、焦点恢复、安全区、大字号、减少动态效果；触感沿用系统偏好，不强制增加重复反馈。HTML演示是展开的Sheet内容，不是已实现完整模态弹层。

## 同步与验证

修改源 → rebuild → validate → test_system；同步验收要求与报告。基础/扩展页均有 `#hour-picker`，主页和所有共享页导航直达规范。新色系使用同一组件和导出契约，不修改图标数量或新造上下箭头代替滚动手势。

双列入口为各主题 `#time-picker`。涉及状态逻辑时，另用现有Node运行 `python skill/scripts/test_picker_state.py --node <Node可执行文件路径>`，验证共同提交/取消、双列未停稳、边界不进位、步进行号映射。此项只执行纯状态逻辑和JS语法，不启动浏览器、不代替手势验收；构建仍只依赖Python标准库。

浏览器人工检查：00/23边界、快速滚动吸附、点击候选、方向键/Home/End、确认值与中心项一致、取消恢复、四模式、2倍文字、窄屏、刷新恢复样张值。JavaScript不可用时按钮保持禁用并解释原因；不把浏览器DOM源码检查报告为实际交互通过。

分钟人工检查：09:30→14:45取消回09:30，再选14:45确认；修改两列取消回14:45。00:00和23:59都可选；分钟首尾不进退小时；同时滚动两列，只停一列不能确认；分钟步进5末项55，无60候选。12小时制与真实业务保存另验。

参考：[Apple Pickers](https://developer.apple.com/design/human-interface-guidelines/pickers)、[SwiftUI wheel](https://developer.apple.com/documentation/swiftui/pickerstyle/wheel)。

循环滚动实现：使用重复的视觉候选段，初始定位于中间段；仅靠近物理滚动边缘时回到等值中间位置；普通停稳不额外强制回中。规范候选仍只有24个小时/对应分钟集合，视觉重复项从辅助技术树隐藏，始终只有一个视觉选中行。键盘方向键同样循环，Home/End仍定位到00/末项。5分钟步进为00↔55，30分钟步进为00↔30；禁止退回边界夹取算法。修改时补测多圈连续滚动、跨零取消和短候选列表。

本滚轮属于App内交互，不是WidgetKit桌面或锁屏控件。小组件只呈现时间摘要与可用快捷动作，编辑时间通过链接进入App。确认/取消沿用共用胶囊按钮；见[WidgetKit与按钮形状契约](widgetkit.md)。

实际停止且真实位置对齐后及时允许确认；拖动、惯性、吸附未结束或手指仍按住时禁用。优先真实停止事件，仅缺失事件使用短静默兜底，不将某个 App 的毫秒数、渲染行数或重复段数固定为通用标准。控制不可见候选挂载和同值重复更新，普通停稳不强制回中。
