# 式样内容与使用边界

## 两套精选风格

| 项目 | 余白 · YOHAKU | 晴日 · SUNNY DAY |
| --- | --- | --- |
| 视觉方向 | 暖纸、细线、克制留白 | 明快蓝色、多色分类、清晰操作层级 |
| 品牌填充 | 焦茶 `#8A6248` | 蓝色 `#399BE8` |
| 底色 / 辅色 | 暖白 `#F6F3ED`；分类与状态各有语义 | 珊瑚 `#F26B5B`、暖黄 `#F4C84A` |
| 建议场景 | 手帐、阅读、笔记、生活方式 | 日程、活动、习惯、轻量效率工具 |
| 配置来源 | `build.py` 中 A 主题 | `themes.json` 中 `sunny-day` |
| Token ID | `A` | `SUNNY-DAY`（配置 ID 为 `sunny-day`） |
| 基础 / 扩展页面 | `a-yohaku.html` / `a-yohaku-ext.html` | `theme-sunny-day.html` / `theme-sunny-day-ext.html` |

场景是设计建议，允许按实际业务调整页面布局。两者共享组件语义、交互规则与校验方式；首页只精选两套，其他五套仍可浏览和生成。

## 包含哪些式样

- 基础：按钮与控件、表单与反馈、日期与列表、整屏日程示例。
- 扩展：深色页面、Sheet、Alert、空态、离线态、引导和图表。
- 可操作 HTML：选择控件、搜索、输入校验、加载/空/失败反馈、弹窗与时段选择，均使用本地演示状态。
- 时间滚轮：仅小时与小时＋分钟两种；24 小时制，默认 1 分钟步进，首尾循环，确认/取消共同提交或恢复两列，分钟不自动进位小时。
- WidgetKit 外观：小/中桌面布局，圆形/矩形/行内锁屏示意。外框由系统决定，不能将 HTML 尺寸视为真实 Widget family 尺寸。
- 共享资源：169 枚线性图标、每主题四组设备尺寸样张、自适应容器和折线压力示意。

静态画板中的按钮、输入框等用于比较外观，不保证可操作。需要体验行为时，使用各主题页下方标有「可操作组件」的区域或时间滚轮演示。日文样本文案只是排版示例，不代表完整的多语言产品。

## 如何复用

先选主题，再按页面任务挑组件。颜色以 `design-tokens.json` 为导出契约，修改来源是 `design_tokens.py` 和主题配置。读取 `themes.<ID>.light / dark / light_hc / dark_hc`，不要在缺失模式时静默回退。

品牌填充使用 `accent`，对应文字使用 `on_accent`；浅底上的文字操作使用 `accent_text`，必要图形使用 `accent_ui`。错误、成功、警告和分类分别使用其语义角色，状态同时配文字或图标。

字体、间距和控件形状遵循 `standards.html` 及 JSON 中的 `typography`、`spacing`、`components`。独立文字按钮为胶囊，图标按钮为圆形；分段控件独立处理。HTML px 和字号倍数只用于样张与压力演示，原生字号、安全区与系统材质须在目标项目映射。

使用 AI 修改时，入口是 [../skill/SKILL.md](../skill/SKILL.md)。生成器修改后运行重建、静态验收和适用回归；截图只用于介绍，应在展示范围发生变化后重新截取。

## 交付边界

项目没有后端、用户数据库、账号系统或真实提交服务。React Native Token 适配器与动作示例在 `native/`，没有完整 App 工程；没有 SwiftUI 组件库或 WidgetKit 扩展。原生平台行为、系统可访问性、持久化和真机效果需在接入项目验收。

详细验收要求见 [../ACCEPTANCE.md](../ACCEPTANCE.md)，本次执行结果见 [../ACCEPTANCE_REPORT.md](../ACCEPTANCE_REPORT.md)。
