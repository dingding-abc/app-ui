# 弹层、表单与输入交互标准

更新：2026-10-08。来源于 App 实际试用中出现的底部选择器裁切、手势争抢、确认响应慢及数字键盘遮挡。这里只提炼跨 App 的交互要求，不纳入牙套周期等业务默认值。

## 日期与时间选择

- 使用独立模态容器，打开时收起键盘，阻止背景触控和滚动。嵌套表单弹窗也应保持一个活动选择器和正确的焦点层级。
- 标题与草稿可换行或独立滚动；日期主体可滚动；时间滚轮不得拥有同方向页面滚动父容器。依据安全区、可用高度和字体大小分配空间，必要时减少邻行，不裁掉选中值和操作。
- 取消／确认固定于安全区内。日期、小时和分钟只更新草稿；确认有效值才回填。取消、遮罩、系统返回、关闭或卸载均丢弃草稿；重新进入回显最后确认值。关闭后焦点回到入口。
- 日历保留切月、快速年月定位和范围校验；切月不自动选日。时间默认分钟步进 1，双列共同确认、首尾循环不跨列进位；显式粗粒度步进不能偷偷舍入旧数据。
- 实际停止且真实位置对齐后及时允许确认。按住、拖动、惯性、吸附或定位未完成时仍禁用。优先平台停止事件，事件缺失才使用可取消的静默兜底。普通停稳不强制额外回中；仅物理循环边缘需要等值平移。
- 控制不可见候选渲染及同值重复更新。具体行数、动画时间和静默阈值由实现和设备验证决定，不照抄某个 App 的参数。

## 键盘与数字输入

一个表单视口只由一个容器负责滚动和键盘避让。Sheet 内表单复用外层滚动；独立页面自身处理避让，避免重复内边距。键盘出现、输入框切换及键盘高度改变时，整个当前输入框可见，主要操作可滚动到达。

单行数字纵向居中，最小触控目标至少 44pt，放大字体时控件随之增高。原生单行输入不要机械套用 Text 行高；多行备注保持顶部对齐。数字支持直接输入，可同时保留加减按钮；空值、非法数值和边界校验由业务契约决定，不以旧值或零值冒充提交成功。

## 契约与修改入口

| 内容 | 权威来源 | 导出／展示 |
| --- | --- | --- |
| 选择器容器与响应要求 | `hour_picker.py → PRESENTATION_CONTRACT` | `design-tokens.json → components.picker_presentation` |
| 表单与数字输入要求 | `component_catalog.py → FORM_CONTRACT` | `design-tokens.json → components.form_interaction` |
| 人读规则及布局示意 | `site_support.py → standards_page()` | `standards.html#picker-presentation` |
| 滚轮范围、步进与草稿 | `hour_picker.py → CONTRACT / TIME_CONTRACT` | 小时／分钟样张及既有导出 |

修改源文件后重建，不手改 HTML 或 JSON 产物。新增契约是兼容性补充，不改变现有颜色、分钟范围或原生颜色适配器。原生工程仍可优先采用系统控件；本标准约束可观察行为，不强制 React Native 或某种实现库。

## 验收场景

| 场景 | 通过条件 |
| --- | --- |
| 页面底部字段、已有 Sheet 内打开 | 选择内容和取消／确认可达，背景不能跟随滑动 |
| 先滚页面再立即拨动小时／分钟 | 操作由目标列接收，两列互不进位，不带动页面 |
| 同时操作两列、手指保持按住 | 所有列停稳且对齐才允许确认，无过早或额外延迟解锁 |
| 多圈循环、取消再进入 | 选中与提交值一致，取消保留原值，无空白边界 |
| 日期切月、越界日期、取消确认 | 导航不提交，越界不可选，草稿确认规则一致 |
| 键盘已打开时切换小时／分钟输入 | 两框分别完整可见，主要操作可到达；不重复增加键盘空白 |
| 小屏、低高度、大字体、明暗／HC | 行高随字体增长，内容可读，关键值和操作不裁切 |
| VoiceOver、返回和减少动态效果 | 名称／值／状态正确，关闭恢复焦点，遵循系统偏好 |

自动验证只覆盖生成和导出一致性、既有纯状态逻辑。HTML 样张仍是展开内容，并非完整日期／时间模态实现；浏览器不能验证 iOS 软键盘或真实惯性。原生验收须记录设备、系统、App 版本、场景与实际结果，未运行写明待验证。
