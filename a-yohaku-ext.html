深色模式规则 Dark Mode

底色

  • 基底用「墨色」（带主题色相的深灰），绝不用纯黑 #000
  • 三级明度层级：底 bg → 卡片 surface → 浮起 elev，替代投影分层

颜色

  • 强调色提亮一档（约 +15~20% 明度）保证暗底对比度
  • 发丝线改为低透明度浅色（白 8~14%），禁止纯白描边
  • 警示 / 印章红同步提亮；正文不用纯白，用米白降刺激

组件

  • Toast 反转为浮起深灰底；Alert 遮罩加深至 60%
  • 图表改用低饱和亮色，禁用大面积渐变
  • 切换动效 0.25s 交叉淡化，跟随系统 appearance

S3Rules规则

Sheet 弹层规则 Sheets

结构

  • 抓手 Grabber：36 × 5pt，圆角 2.5，置于顶部居中，距顶 12
  • 半屏 Sheet 顶部圆角 16~18pt，底部贴安全区（Home 指示条留 34pt）
  • 遮罩：墨色 40%（深色模式 60%），下层内容保留可见但不可点

层级与类型

  • 半屏：轻选择（排序 / 筛选 / 分享），选项 ≤ 5 行
  • 全屏 Sheet：创建 / 编辑表单，导航栏 = 取消(左) · 标题(中) · 保存(右，强调色)
  • Action Sheet：含破坏性操作时，危险项置顶标红，取消独立成块与选项隔 8pt

交互（HIG）

  • 下拉可关闭；表单有改动时下拉弹出「放弃编辑？」确认
  • 弹出动画 0.3s spring；键盘升起时 Sheet 自动避让

空状态规则

  • 插画为匀线线稿，线宽随画幅放大（空态画幅 140 → 2.4pt 主线 / 2pt 细节），高分屏下不发虚；主体发丝灰、仅一处强调色点睛，配淡椭圆落影
  • 文案三段式：状态陈述（发生了什么）→ 安抚/解释 → 引导（下一步），日语敬体、不用感叹号
  • CTA 分级：可行动 → 主按钮；可调整 → 柔底；不可行动（如离线）→ 次级按钮

必备场景清单

  • 首次使用空态（带引导 CTA）/ 筛选无结果 / 搜索无结果
  • 离线 / 加载失败（重试）/ 通知清空 / 收藏为空
  • 每个空态都要回答：「用户现在能做什么？」

引导页规则

  • 3 页封顶，每页一个信息点；可整页跳过（右上スキップ，末页隐藏）
  • 插画 = 匀线稿 + 单色点睛 + 大面积留白，与空状态同一套插画语言；线宽随画幅缩放（引导画幅 230 → 2.6pt），保持视觉线重恒定
  • 页点：当前页拉长为圆角条（22pt），其余 6pt 圆点

文案与 CTA

  • 标题汉字短语（4~5 字）+ 罗马音/英文小标 + 两行敬体描述
  • 前两页用幽灵按钮「次へ」降低压迫感，末页主按钮「はじめる」
  • 支持左右滑动翻页；仅首次启动显示，二次进入直达首页

C3Rules规则

图表规则 Charts

视觉

  • 网格 = 1px 发丝线，最多 4 条；保留必要刻度、单位与数值摘要，数值可在图中或可访问的数据列表中读取
  • 折线 2pt 圆角连接，面积填充 = 主色 10% 透明度；当前点加光晕
  • 柱状：非活跃柱用 fill-strong 中性灰，仅高亮柱用主色
  • 环形：10pt 环宽、平头端点，中心放大数字 + 小标签

数据色板

  • 序列使用可辨识的数据色；分类图表同时提供文字、数值或形状提示
  • 涨跌语义随业务地区配置，必须同时显示正负号或方向文字，不能只靠颜色
  • 深色模式使用独立语义数据色，按实际背景验证对比度

A3Rules规则

无障碍规则 Accessibility

增强对比度 Increased Contrast

  • 系统开启后走 prefers-contrast: more；页内 .hc 类供对照演示
  • HC 按浅色与深色分别推导文字、功能图标、控件边界和彩底字色， 底色与布局一律不动，避免整体重绘
  • 发丝线在 HC 下提升到 sub 同级明度保证分隔可辨；正文对比不低于 7:1

Dynamic Type

  • 正文类字号一律写成 calc(Npx * var(--dt-scale,1))， 由 --dt-scale 统一驱动；原生工程使用系统 Text Style，单独验证各档位
  • 阶梯：標準 1.0 / 大 1.176 / 特大 1.41 / 排版压力 1.75×（仅为 HTML 比例演示，不对应 iOS 系统档位）
  • 放大时容器必须能撑高，禁止固定高度裁切；单行标题允许换行
  • SwiftUI 侧直接用系统 Text Style（body / footnote / caption…），系统自动缩放
